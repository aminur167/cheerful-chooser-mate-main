# Cheerful Chooser - Interactive Decision Maker

A clean, responsive decision utility application designed to help individuals and teams make quick, unbiased choices - from picking lunch spots and assigning meeting presenters to choosing team activities.

## Features

- **Custom Lists**: Quickly input, edit, or import candidate options.
- **Randomizer Wheel / Draw**: Fair pseudo-random selection with fun visual suspense.
- **Exclusion Mode**: Option to remove selected items after draw to prevent duplicates.
- **Mobile Friendly**: Lightweight interface optimized for quick decisions on any device.

## Tech Stack

- **Framework**: TanStack Start / React, TypeScript
- **Styling**: Tailwind CSS, modern responsive design
- **Tooling**: Vite, Bun
